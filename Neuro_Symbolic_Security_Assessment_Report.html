Section 1

Executive summary

This report presents the output of a neuro-symbolic evaluation pipeline applied to 11 canonical architectural risk findings identified in an Aave-derivative lending protocol. Each finding was independently assessed by a probabilistic large language model (Node 07), cross-checked against deterministic on-chain evidence gathered via Foundry runtime validation (Node 16), and mathematically combined using Dempster-Shafer evidence fusion (Node 17). A final evaluation layer (Node 18) measured how much deterministic grounding changed the original LLM assessment, without treating that change as a claim of improved accuracy.

Section 2

Assessment methodology

The assessment pipeline combines two structurally different reasoning modes — probabilistic and symbolic — into a single, mathematically principled evaluation, following a Dempster-Shafer evidence-fusion architecture.

Stage 1 — probabilistic LLM baseline

A large language model reasons over a structured architectural model of the protocol and identifies architectural security risks against a fixed, closed taxonomy of 11 canonical findings (F01–F11). Each finding is assigned a confidence score reflecting the model's certainty in its own specific causal claim — not merely whether supporting evidence exists.

Stage 2 — deterministic evidence anchor

Each finding is independently checked against on-chain evidence: Foundry runtime calls verifying contract existence, resolver behavior, and access-control wiring. This stage is frozen and read-only, and its output is never treated as ground truth — it is one body of evidence, not an oracle of correctness.

Stage 3 — Dempster-Shafer evidence fusion

The LLM's assessment and the deterministic evidence are combined using the classical normalized Dempster's rule of combination, over a binary frame of discernment Θ = {R, ¬R} (R = "this finding is a substantiated risk"). Each source contributes a mass function m(R), m(¬R), m(Θ); combination produces a belief/plausibility interval [Bel(R), Pl(R)], a conflict measure K, and a decision-oriented pignistic probability BetP(R).

Stage 4 — grounding effect evaluation

The final stage measures change = BetP(R) − LLM confidence per finding, and reports divergence, conflict, and uncertainty as raw, uninterpreted quantities. It does not compute a calibration score, and does not treat a larger or smaller change as evidence of correctness.

Independence note The Evidence Review Agent (ERA), which produces the plain-language explanations referenced throughout this report, is not used as a fusion input. ERA reads Node 16's deterministic output directly, so combining it with Node 16 via Dempster's rule would double-count the deterministic signal. Only Node 07 (the untouched LLM baseline) and Node 16 are fused.

Section 3

Protocol architecture overview

The assessed protocol follows Aave's registry-centric architecture. A single PoolAddressesProvider acts as a service locator, resolving the addresses of the Pool implementation, the ACL Manager, the Pool Configurator, the Umbrella (deficit-elimination) authority, and the Price Oracle. The Pool contract itself is deployed behind an upgradeable proxy pattern (VersionedInitializable), delegates asset custody and accounting to external aToken and variable-debt-token contracts, externalizes interest-rate computation to a separate strategy contract, and supports flashloans that invoke arbitrary external receiver contracts mid-transaction. Users may additionally delegate account-level permissions (collateral flags, eMode) to third-party Position Manager addresses.

This architecture concentrates several distinct forms of privileged authority behind a small number of resolvable addresses — which is precisely the structural pattern the 11 canonical findings in this assessment are built to characterize.

Section 7

Deterministic validation

Deterministic validation (Node 16) evaluates each finding against a set of formally defined propositions — architectural evidence claims, resolver checks, and runtime existence checks — using three-valued (Kleene K3) logic: a proposition is SUPPORTED, CONTRADICTED, or UNRESOLVED. A finding-level status is derived from its propositions: contradiction dominates, full support requires unanimity, and anything else resolves to a mixed or unresolved state. This node is frozen and read-only for the duration of this assessment, and its output is explicitly never treated as ground truth — it is one independent evidence source among several, not an arbiter of correctness.

Section 8

Neuro-symbolic evidence fusion

Dempster-Shafer combination fuses two independent mass functions — one from the LLM (Node 07), one from deterministic evidence (Node 16) — into a single combined mass, using the classical normalized rule:

K = m1(R)·m2(¬R) + m1(¬R)·m2(R)
m12(A) = ΣB∩C=A m1(B)·m2(C) ÷ (1 − K)

Because Node 07 structurally never asserts ¬R (it is a risk-identification agent, not a risk-refutation one), its mass is m(R) = confidence, m(¬R) = 0, m(Θ) = 1 − confidence. This has a proven mathematical consequence: whenever deterministic evidence shows no contradiction, the combined belief simplifies to combined_R = s + c(1−s), where s is the deterministic support fraction and c is the LLM's confidence — an outcome that is always greater than or equal to c. This is why every finding in this run increased and none decreased: it is a structural property of the fusion, verified against the actual pipeline output to within 1e-5, not a coincidence specific to this protocol.

The primary comparison metric between the LLM's original view and the fused result is D = |confidence − BetP(R)|. Where the fused belief sits relative to the raw [Bel, Pl] range is reported descriptively only — it is not treated as a pass/fail test of LLM overconfidence, since that direction is structurally expected under the current mass-assignment scheme rather than diagnostic of any individual finding.

Section 10

Limitations

  • No independent ground truth. None of the 11 findings has an independently verified true/false outcome external to this pipeline. The one real independent source available — the Sigma Prime implementation audit — covers only 2 informational issues unrelated to most of these architectural findings, and does not constitute ground truth for them.
  • Formal empirical calibration is unavailable. Brier score, expected calibration error, or accuracy cannot be computed without independent outcomes. This is stated explicitly rather than approximated or omitted silently.
  • Reproducibility has not been formally measured. Node 16 and the Dempster-Shafer combination math are deterministic by construction (same input, same output, verified via self-tests). Node 07 is not: in an earlier pipeline run on identical input, F11's LLM confidence was 0.60; in the run reported here, it was 0.90. This report reflects a single run; a dedicated repeated-run experiment (N ≥ 5) is required to characterize this variability formally.
  • Dempster combination has known limitations. Real contradiction (K > 0, as in F05 and F10) is absorbed into the conflict statistic rather than proportionally lowering the fused belief — a documented property of the classical combination rule, not an error in this implementation.
  • Mass-assignment granularity is coarse. Deterministic mass is derived from small integer proposition counts (typically 3–4 per finding), which structurally bounds how much any single finding's fused belief can move, independent of the true strength of the underlying evidence.
  • Primary DST view only. This report uses Node 17's primary evidence view, which includes an always-unresolved "experiment" proposition (no Foundry behavioural tests have yet been executed for any finding). A sensitivity view excluding that proposition is computed separately and is not the basis for the figures above.

Section 11

Conclusion

The central result of this assessment is not any individual finding's severity or confidence score — it is the demonstration that a probabilistic LLM risk assessment can be mathematically grounded against independent deterministic evidence, with the resulting agreement, disagreement, and residual uncertainty reported transparently rather than collapsed into a single opaque number. Across 11 findings, grounding consistently raised the assessed confidence, a predictable consequence of the current mass-assignment structure rather than an independent validation of the underlying architecture. Two findings, F05 and F10, demonstrate that real evidentiary conflict can and does surface through this process, and is preserved rather than smoothed over even when the headline fused value remains high.

This pipeline does not, and does not claim to, establish that the assessed protocol is secure or insecure. It establishes a repeatable, mathematically auditable method for combining what an LLM believes with what deterministic evidence shows — and for saying, precisely, where those two things agree, where they conflict, and where the honest answer is that neither can currently be checked against ground truth.
